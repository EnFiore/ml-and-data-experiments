# PROGETTI VARI DI ML E DATA ANALYSIS
## 1. Spark Data Analysis Wikipedia article
Progetto finale del Corso sui Big data di profession AI del master in Data Science

Il progetto ha due obiettivi principali su un dataset di articoli Wikipedia suddivisi per categoria tematica (Cultura, Economia, Medicina, Tecnologia, Politica, Scienza, ecc.):

**1. Analisi esplorativa dei dati (EDA)**
Caratterizzare i contenuti per categoria attraverso:

- conteggio articoli per categoria
- lunghezza media (parole) per articolo
- articolo più lungo e più corto per categoria
- word cloud per individuare i termini più frequenti/rilevanti

**2. Classificatore automatico**
Costruire un modello ML che classifichi gli articoli nella categoria corretta, addestrato sul testo contenuto in due colonne: *summary* (sommario breve) e *documents (testo completo).*
